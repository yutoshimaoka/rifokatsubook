# リフォ活 情報サイト設計ドキュメント

## 目的
リフォ活は、住宅リフォーム前の不安を解消し、費用・業者選び・補助金・修理判断を分かりやすく支援する情報サイトです。

本ドキュメント群は、サイト設計・SEO記事制作・デザイン制作・CV導線設計を育てていくための設計資料です。

## 現在の決定事項

- サイト名：リフォ活 入門Book
- ロゴ表記：上段に「リフォ活」、下段に小さく「入門Book」
- 方向性：信頼できる住宅リフォーム情報サイトとして育てる
- 主要テーマ：費用、業者選び、補助金、修理判断
- 主な対象：築10〜30年の住宅所有者
- 初期サイトの形：トップページ、カテゴリーページ、記事ページから小さく始める
- 初期カテゴリ：外壁・屋根、水回り、住宅設備、費用・補助金、業者選び
- 初期対象外：マンションリフォーム、介護・バリアフリー
- ファーストビューのメインコピー：損をしないための住まいのリフォ活入門Book
- ファーストビューのサブコピー：費用・修理の判断・補助金・業者選びまで。リフォーム前に知っておきたい情報を、やさしく整理する住宅リフォーム情報サイトです。
