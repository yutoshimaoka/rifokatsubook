# Rifokatsu WordPress Theme

## 導入手順

1. `wp-content/themes/rifokatsu/` をWordPress環境の同じ場所へ配置します。
2. WordPress管理画面の「外観 > テーマ」から `Rifokatsu` を有効化します。
3. 「設定 > パーマリンク」で保存し、`case` 投稿タイプのURLを再生成します。
4. 「外観 > メニュー」で主要ナビゲーションを作成し、`Primary Menu` に割り当てます。
5. 「固定ページ」を作成し、「設定 > 表示設定」でホームページに指定します。

## 投稿管理

- 新着記事: WordPress標準の「投稿」を使います。トップページには最新6件が表示されます。
- 施工事例: 管理画面の「施工事例」を使います。トップページには最新1件が表示されます。
- 施工事例の概要: 編集画面の「施工事例の概要」で施工場所、住宅種別、工期、概要テキストを入力します。

## 画像

- 通常投稿と施工事例の一覧画像はアイキャッチ画像を使います。
- FVやアイコンなどの固定画像は `assets/images/` に格納しています。
